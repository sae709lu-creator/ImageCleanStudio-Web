# Image Clean Studio 網頁版

將 ZIP 解壓縮到本機，以 Chrome 或 Edge 開啟 `index.html`。請保留同資料夾的 JS 與 CSS 檔案。執行時無需安裝 Node.js、Python 或伺服器，且不需要網路。專案沒有部署到外部網站。

## 使用

1. 在「批次處理」拖曳圖片，或選取 PNG、JPG、WebP 圖片及資料夾。
2. 選擇清理、轉檔並清理，或原樣複製。原樣複製會保留元數據，並驗證 SHA-256。
3. 可啟用「使用群組與情境命名」，在清單編輯或對選取列批次套用。預設重複時加上 `_01`、`_02`。剪貼簿批次貼上需瀏覽器授權，行數須與所選圖片相同。
4. 按「開始處理」。完成或取消後，已通過驗證的輸出會出現在「處理紀錄」，可個別下載或下載本批 ZIP。ZIP 只收錄可下載的圖片，保留 UTF-8 檔名。
5. 查看「元數據檢視器」可讀取容器標記、PNG 文字欄位與已知 Stealth 資料。檢視內容及處理結果留在目前頁面，重新載入後會清空。

## 清理與畫質

- 清理流程重新編碼並重新讀取輸出，檢查 PNG chunks、JPEG markers 或 WebP RIFF chunks，並檢查已知 Stealth 簽名。
- 在一般 8 位元非交錯 RGB／RGBA PNG 中，直接檢查原始樣本。含色彩描述或 EXIF 方向時，交由瀏覽器解碼至 sRGB，PNG 輸出會再次核對編碼前後的樣本。色彩轉換、方向、縮放或 Alpha 正規化會改變與來源檔直接比較的條件。
- JPG、WebP 使用瀏覽器編碼並顯示 PSNR。色度取樣、WebP 編碼器參數與輸出體積取決於瀏覽器。PNG 是無損選項。
- 若圖片有已知 Alpha 隱寫，清理可能改變透明度，並在處理紀錄說明。已知簽名以外的浮水印或隱寫技術未涵蓋。
- 16 位元 PNG 和動態圖片只支援原樣複製。限制為單張 100 MiB、2,000 萬像素、單邊 16,384，以及同批可下載結果總量 512 MiB。
- 網頁版提供瀏覽器下載，儲存位置與既有檔案衝突由瀏覽器管理。桌面版的目錄樹、群組子資料夾、CSV 命名對照表、常用名稱管理與特定格式編碼選項屬於桌面功能。

## 開發測試

需 Node.js、Chrome 或 Edge。在網頁版原始碼目錄執行 `npm install` 和 `npm test`。非預設瀏覽器安裝位置可指定 `ICS_CHROME`、`ICS_EDGE`。測試圖片、瀏覽器下載及 ZIP 解壓皆使用暫存目錄。詳見 `TEST_REPORT.md`。
